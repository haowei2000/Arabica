A small surface.
A clear contract.

Clients submit typed commands. The session layer validates and sequences each run. The runtime orchestrates model calls and tools, then emits canonical events. Every host shares that same contract.

Get started

Build from source with Rust 1.88 or newer. Configure an OpenAI-compatible endpoint before your first run.

From clone to first prompt

Arabica is in active development. The source is the most direct way to try it and inspect how it works.

  1. Clone the repository.
  2. Build the CLI in release mode.
  3. Set the provider environment variables, then run a prompt.
Full setup in the README ↗
# Build
git clone https://github.com/haowei2000/Arabica.git
cd Arabica
cargo build --release -p arabica-cli

# Configure your provider locally
export OPENAI__API_KEY="your-key"
export OPENAI__BASE_URL="https://api.openai.com/v1"
export OPENAI__MODEL="your-model"

# Run a one-shot task
./target/release/arabica -p "Explain this workspace"
