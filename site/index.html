── What is Structure

Structure runs a coding agent as a canonical command/event protocol: clients submit CommandEnvelopes, the session layer sequences them, and the runtime emits EventEnvelopes. Three surfaces share one core — a fullscreen terminal TUI, one-shot arabica -p for scripts, and arabica acp for editors like Zed. There is no frontend and no server-side state to leak; sessions are append-only JSONL you own.

── Highlights

Fullscreen TUI

Scrolling history pane, Claude-style divider, pinned editor. Tool calls fold to one line and flip ✓/✗ in place; file edits render as colored diffs. ↑/↓ walks blocks, Enter copies them.

Workspace instructions

An AGENTS.md in the workspace root becomes a standing system instruction — re-read every turn, layered deepest-first when nested.

Write checkpoints

/diff shows the agent's net file changes; /undo reverts its last write call — all-or-nothing, never touching your own edits.

MCP servers

Declare stdio or streamable-HTTP servers in ~/.arabica/config.toml or per-session from an ACP client. Credentials never reach the session log.

Session memory

File-backed compaction archives older context losslessly; memory_search/memory_read recover it on demand. /context shows exactly what the next request carries.

Multi-provider

OpenAI Chat Completions, OpenAI Responses, Anthropic Messages — with true streaming. Gemini dialects are next.

── Install

Grab a binary from GitHub Releases, or build from source:

git clone https://github.com/haowei2000/Arabica
cd Structure
cargo build --release -p arabica-cli
./target/release/arabica --help

Configure a provider (OpenAI-compatible endpoint works out of the box):

mkdir -p ~/.arabica
cat > ~/.arabica/config.toml <<'EOF'
[provider]
api_type = "open_ai_chat_completions"
api_key  = "sk-..."                 # keep the file chmod 600
base_url = "https://api.openai.com/v1"
model    = "gpt-4.1"
EOF
chmod 600 ~/.arabica/config.toml

Then drop an AGENTS.md in your project and start:

cd your-project
arabica               # fullscreen TUI
arabica -p "..."      # one-shot, for scripts
