A small surface.
A clear contract.

Clients submit typed commands. The session layer validates and sequences each run. The runtime orchestrates model calls and tools, then emits canonical events. Every host shares that same contract.

Install Arabica

Choose a verified release download or build the published Rust package. Both install the arabica command.

macOS + Linux

Download with curl

The installer detects your CPU, checks the release SHA-256 file, and places the binary in ~/.local/bin.

curl -fsSL https://haowei2000.github.io/Arabica/install.sh \
  -o install-arabica.sh
sh install-arabica.sh
~/.local/bin/arabica --help

Set ARABICA_INSTALL_DIR for another directory or ARABICA_VERSION=v0.1.1 to pin a release. Windows archives are on GitHub Releases ↗

Rust 1.88+

Install with Cargo

Build arabica-cli from crates.io. Cargo puts the arabica binary in ~/.cargo/bin.

cargo install arabica-cli --locked
arabica --help

Prefer the repository source? Build the workspace with Cargo ↗

Then configure a provider

Arabica uses named provider and model entries, with API keys stored separately. Start from the guided configuration example and add Blend routing when you need multiple models.

Open the configuration guide ↗
[providers.openai]
api_type = "open_ai_responses"
base_url = "https://api.openai.com/v1"
api_key_env = "ARABICA_PROVIDER_OPENAI_API_KEY"

[models.default]
provider = "openai"
model_id = "your-model-id"

[blend]
default_policy = "coding"

[blend.policies.coding]
version = 1
default_model = "default"
