Configuration guide

Make Arabica yours.

Start with a provider and model. Then choose how the CLI, tools, model routing, and HTTP host should behave.

First run

The CLI reads $ARABICA_HOME/config.toml, defaulting to ~/.arabica/config.toml. A single-model setup needs an endpoint, model ID, and API key.

mkdir -p ~/.arabica
cat > ~/.arabica/config.toml <<'EOF'
[provider]
api_type = "open_ai_chat_completions"
base_url = "https://api.openai.com/v1"
model = "your-model"
EOF
arabica auth login
arabica config
arabica -p "Explain this workspace"

arabica auth login prompts without echoing the key and saves it in ~/.arabica/auth.json. arabica config shows the effective endpoint, model, paths, and tools without printing the key. Run arabica for interactive chat or arabica acp for an editor.

Provider settings

These keys belong under [provider] in the user config. The historical OPENAI__* variable names also work with other providers when you choose a matching API type and endpoint.

KeyMeaningOverride
api_typeWire protocol; default open_ai_chat_completions. Implemented: open_ai_chat_completions, open_ai_responses, anthropic_messages, gemini_generate_content. gemini_interactions is declared but not implemented.--api-type, ARABICA__API_TYPE
base_urlProvider API root, such as https://api.openai.com/v1.--base-url, OPENAI__BASE_URL
modelProvider model ID. In a Blend setup, the default alias can supply this value.--model, OPENAI__MODEL
api_keyKey stored in this file. Prefer saved auth or an environment variable.OPENAI__API_KEY, arabica auth login
thinkingoff for any API type; on for Chat Completions; low, medium, or high for Responses.Saved workspace choice

If config.toml includes api_key or MCP credentials, run chmod 600 ~/.arabica/config.toml on macOS/Linux. Arabica rejects credential-bearing files that are world-readable or symlinks. Never put a key in a CLI flag.

Priority and paths

The CLI deliberately ignores project-local .env files. ARABICA_HOME changes the user config, saved-key, session, and memory location; the default is ~/.arabica. Saved workspace model and thinking choices are under $ARABICA_HOME/workspaces/<workspace-id>/config.toml; arabica config prints the exact path.

SettingPriority, highest first
model--model → workspace choice → OPENAI__MODEL → [provider].model → Blend default alias
base_url / api_typeCLI flag → environment variable → user [provider]
API keyOPENAI__API_KEY → user [provider].api_key → saved auth.json
thinkingWorkspace choice → user [provider].thinking → off

ARABICA__MODELS adds comma-separated model IDs to the terminal and ACP selectors; it does not configure Blend routing.

CLI options

These affect one invocation and do not edit the user config.

Model routing with Blend

Define aliases under [models.<alias>] and an explicit [blend]. All models share the provider API type, base URL, and key. Routing applies in chat, -p, and ACP.

[provider]
base_url = "https://api.openai.com/v1"

[models.fast]
model_id = "your-fast-model"
[models.strong]
model_id = "your-strong-model"

[blend]
policy_id = "coding"
version = 1
default_model = "strong"
after_tool_success = "fast"
after_tool_error = "strong"
recovery_model = "strong"
recovery_after_no_progress_steps = 2
minimum_model_dwell_steps = 2
tool_call_capable_models = ["fast", "strong"]
typed_completion_capable_models = ["strong"]
KeyMeaning
model_idProvider model ID behind each alias.
policy_id / versionRoute identity; defaults cli-config and 1.
default_modelRequired starting alias.
after_tool_success / after_tool_errorOptional next-call aliases after a tool succeeds or fails.
recovery_modelOptional alias for repeated no-progress steps.
recovery_after_no_progress_stepsPositive recovery threshold; default 2.
minimum_model_dwell_stepsCalls before an ordinary switch; default 1. Error and recovery routes may switch sooner.
tool_call_capable_modelsAliases certified for tool calling.
typed_completion_capable_modelsAliases certified for typed terminal completion.

Every referenced alias must exist. Run arabica config to inspect the effective mapping.

MCP tools

Put [[mcp]] entries in the user config for chat and -p. Each server chooses exactly one transport: an absolute local command or a streamable HTTP url.

[[mcp]]
name = "local-docs"
command = "/absolute/path/to/docs-mcp"
args = ["--verbose"]
[mcp.env]
DOCS_TOKEN = "your-token"

[[mcp]]
name = "remote-search"
url = "https://mcp.example.test/mcp"
[mcp.headers]
Authorization = "Bearer your-token"

name identifies a server; args passes stdio arguments; env adds local environment variables; headers goes to the HTTP server. Keep credentials owner-only. An ACP client can supply servers and its entry wins when names match. Tool calls still pass through permission handling.

HTTP server settings

Start with cargo run -p arabica-server. The server reads OPENAI__API_KEY and OPENAI__BASE_URL, plus OPENAI__MODEL for a single-model run. ARABICA__BLEND_MODELS supplies models instead when Blend is enabled.

VariableMeaning / default
ARABICA__API_TYPEProvider wire protocol; default Chat Completions.
ARABICA__PORTLoopback HTTP port; default 4096.
ARABICA__TOOL_ROOTRoot given to the local runner; default current directory. Choose this boundary carefully.
ARABICA__BLEND_MODELSComma-separated alias=model-id entries.
ARABICA__BLEND_DEFAULTStarting alias; default first entry.
ARABICA__BLEND_AFTER_TOOL_SUCCESS / ARABICA__BLEND_AFTER_TOOL_ERRORAlias after tool success or failure.
ARABICA__BLEND_RECOVERY_MODEL / ARABICA__BLEND_RECOVERY_AFTER_NO_PROGRESS_STEPSRecovery alias and step threshold; default threshold 2.
ARABICA__BLEND_MINIMUM_MODEL_DWELL_STEPSOrdinary route hold; default 1.
ARABICA__BLEND_TOOL_CALL_MODELS / ARABICA__BLEND_TYPED_COMPLETION_MODELSComma-separated certified aliases.
ARABICA__BLEND_POLICY_ID / ARABICA__BLEND_POLICY_VERSIONRoute identity; defaults env-rules and 1.
ARABICA__COMPACTION_STRATEGYfile_backed_gc (default), pointer_gc, or disabled.
ARABICA__ARCHIVE_ROOTFile archive directory; default target/arabica-runtime-memory.
COMPACTION_EFFORT / PGC_EFFORTPositive cost threshold; default 1. PGC_EFFORT is a legacy fallback.
PGC_CONTINUATION_PROBABILITY_BPSPointer-GC estimate in basis points, 0–10000; default 7500.

The server loads a local .env file, unlike the CLI, and listens on 127.0.0.1. Its endpoints are /health, /v1/schema, /v1/commands, and /v1/events.

Installer options

The curl installer supports macOS and Linux on x86_64 and ARM64 and verifies the archive SHA-256 before installing. Windows ZIPs and checksum files are on GitHub Releases.

VariableMeaning / default
ARABICA_INSTALL_DIRDestination; default ~/.local/bin. Add it to PATH if needed.
ARABICA_VERSIONRelease tag such as v0.1.1; default latest.
