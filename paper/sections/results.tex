\subsection{Ablation Study}

We ablate the five design components of the layer --- path addressing,
multi-level disclosure, source evaluation (rating), event-level
garbage collection, and the audit log --- by disabling each in turn
while keeping the rest of the system identical.
\textbf{(A1) No paths.} Entries are stored with a flat identifier;
\texttt{list} and \texttt{glob} degrade to full scans.
\textbf{(A2) Single level.} Every read returns full \textsc{detail};
\textsc{glance} and \textsc{overview} projections are disabled.
\textbf{(A3) No rating.} The \texttt{rate\_context} tool is hidden and
retrieval no longer blends or filters on $\bar r$; only
semantic similarity orders results.
\textbf{(A4) No GC.} All events are pinned; the prompt grows until
the hard window limit forces oldest-first truncation.
\textbf{(A5) No audit replay.} Context events are no longer persisted
as an ordered log; the agent cannot re-read prior context deterministically.
