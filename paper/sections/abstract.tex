Long-running LLM agents already rely on familiar context mechanisms:
retrieval, history buffers, tool descriptions, artifact stores, and
agent memory. The missing piece is less another memory algorithm than a
single operational contract for deciding what enters the prompt, what
remains addressable outside it, and how those decisions can be replayed.
We present \textsc{Structure}, an event-sourced context manager for
long-running agents. Durable material is stored behind typed
hierarchical paths and disclosed through a fixed three-level interface
(\textsc{glance}, \textsc{overview}, \textsc{detail}); transient
trajectory is represented as typed events and materialised by a
deterministic short-context policy that pins task anchors, expires
recent plan--act signals, drops high-frequency noise, and admits
structured summary events without rewriting the audit log. This turns
prompt construction into a reproducible materialisation problem rather
than a mixture of independent prompt channels. We instantiate
\textsc{Structure} as an open-source orchestration platform and narrow
the empirical claim to long-term memory and context-selection
benchmarks: LongMemEval, LoCoMo, and LongMemEval-V2. The artifact
includes dataset adapters, deterministic scorers, fixture-level
integration tests, memory-baseline registries, and live-run scripts
comparing \textsc{Structure} with full-context and retrieval baselines.
