We presented \textsc{Structure} as an operational contract for context
materialisation in long-running LLM agents. Rather than foregrounding
the familiar observation that agents use retrieval, history, tools, and
memory, the system specifies how those sources become prompt candidates
and how transient trajectory becomes a replayable short-context slice.
Path-addressable disclosure controls durable entries; event visibility
controls short context through pinned anchors, per-type TTLs, noise
filters, and structured summaries. The current artifact narrows the
empirical question to memory/context-selection benchmarks and validates
the evaluation harness before making live model-performance claims. A
natural next direction is to let the agent \emph{learn} both disclosure
and compression policies by treating path selection, disclosure level,
event pinning, and summary emission as lightweight actions.
